# Learn English Bot

Telegram-бот-викторина для изучения английского (`@fastapiwb_bot`).

Вопросы и уровни сложности хранятся в базе данных (SQLite), а не в `.txt`
файлах, как раньше. Управлять ими можно через веб-интерфейс, защищённый
логином и паролем.

## Стек

- **FastAPI** — Admin API + веб-страницы управления
- **SQLAdmin** — веб-админка поверх БД (таблицы, формы, поиск)
- **SQLAlchemy** — работа с базой данных
- **SQLite** — сама база (файл `english_bot.db`, создаётся автоматически)
- **pyTelegramBotAPI (telebot)** — сам телеграм-бот, режим polling
- **bcrypt** — хэширование паролей аккаунтов админки

## Установка (Windows, PowerShell)

Открой папку проекта в PowerShell или в терминале VS Code и выполни по порядку:

```powershell
# 1. Создать виртуальное окружение
python -m venv .venv

# 2. Активировать его
.venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt
```

Если `python` не находится — установи Python 3.11+ с python.org и поставь
галочку "Add python.exe to PATH" при установке.

## Первый запуск

### 1. Перенос старых вопросов в базу (один раз)

В папке `txt/` лежат старые файлы с вопросами. Чтобы перенести их в базу:

```powershell
python scripts\seed_from_txt.py
```

Скрипт создаст файл `english_bot.db` и заполнит его уровнями и вопросами.
Повторный запуск ничего не сломает — уровни, которые уже есть, пропускаются.

### 2. Создание аккаунта для входа в админку (один раз)

```powershell
python scripts\create_admin.py
```

Спросит логин и пароль в консоли (ввод пароля скрыт). Можно запускать
ещё раз с тем же логином, чтобы сменить пароль, или с другим логином,
чтобы создать ещё один аккаунт.

## Запуск Admin API + веб-интерфейсов

```powershell
python run_api.py
```

Всё, что ниже, требует входа — открыв любой адрес без логина, тебя
перекинет на страницу входа.

### 📝 /manage — редактор слов (рекомендуется для повседневной работы)

**http://127.0.0.1:8000/manage**

- список всех уровней с количеством слов в каждом
- **«+ Новый уровень»** — создать уровень (key латиницей + название)
- **«Список слов»** — открывает уровень целиком одним текстом в формате
  `слово | перевод | подсказка`, одна строка = одно слово. Правишь текст
  как обычный блокнот (дописал/удалил/поправил строку) и жмёшь
  «Сохранить» — весь список слов уровня в базе заменяется на то, что
  получилось. Перевод можно указывать несколько вариантов через `/`.
- **«Переименовать»** — изменить отображаемое имя и описание уровня
- **«Удалить»** — удалить уровень со всеми его словами целиком (спросит
  подтверждение, действие необратимо)

### 🖥️ /admin — обычная табличная админка (для точечных правок)

**http://127.0.0.1:8000/admin**

Классический интерфейс: разделы **Уровни** и **Вопросы**, можно искать,
редактировать и удалять отдельные записи по одной, фильтровать вопросы
по уровню. Удобна, когда нужно поправить/удалить одно конкретное слово,
а не весь список разом.

### 📋 /docs — API-документация

Для программного доступа или массовой вставки вопросов через прямой
HTTP-запрос (`POST /levels/{level_id}/questions/bulk`).

## Запуск бота

В **отдельном** окне терминала:

```powershell
.venv\Scripts\activate
python run_bot.py
```

Бот подключится к Telegram и начнёт отвечать на сообщения. Останавливается
через Ctrl+C. Новые уровни/слова, добавленные через `/manage` или `/admin`,
подхватываются ботом сразу — перезапускать его не обязательно.

## Про авторизацию

Логин защищает и `/manage`, и `/admin` — оба используют одну и ту же
таблицу аккаунтов (`admin_users`) в базе, пароли хранятся только в виде
bcrypt-хэша, никогда открытым текстом.

Ключ для подписи сессионных cookie при первом запуске сохраняется в файл
`.secret_key` рядом с проектом (в `.gitignore`, в репозиторий не
попадает) — так вход не будет слетать при каждом перезапуске сервера.
Если файл удалить, все залогиненные до этого сессии станут
недействительными, и надо будет войти заново — это не страшно.

Чтобы добавить ещё одного человека с доступом к админке — просто ещё раз
`python scripts\create_admin.py` с другим логином. Чтобы отозвать доступ —
через `/admin` можно снять галочку `is_active` у аккаунта в разделе БД,
либо попросить пересоздать пароль.

## Добавление нового уровня — пример

**Через /manage (рекомендуется):**

1. Открой `http://127.0.0.1:8000/manage`, войди под своим логином.
2. Впиши `key=food`, `name=🍎 Еда` → «+ Новый уровень».
3. Откроется пустой редактор — вставь весь список слов сразу:
   ```
   apple | яблоко | red or green fruit
   bread | хлеб | you eat it every day
   ```
4. «Сохранить».

**Через API** (для скриптовой/массовой загрузки):

1. Открой `http://127.0.0.1:8000/docs`.
2. `POST /levels`: `{"key": "food", "name": "🍎 Еда"}`.
3. `POST /levels/{id}/questions/bulk`: `{"text": "apple | яблоко | ..."}`.

## О безопасности токена

Файл `key.py` с токеном бота добавлен в `.gitignore` — он не должен
попадать в git-репозиторий или куда-либо ещё, где его смогут увидеть
посторонние. Если токен всё же где-то засветился — можно бесплатно
перевыпустить его через [@BotFather](https://t.me/BotFather) командой
`/mybots` → выбрать бота → `API Token` → `Revoke current token`.
