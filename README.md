# Learn English Bot

Telegram-бот-викторина для изучения английского (`@fastapiwb_bot`).

Вопросы и уровни сложности хранятся в базе данных (SQLite), а не в `.txt`
файлах, как раньше. Добавлять новые уровни и вопросы теперь можно через
Admin API (FastAPI) — прямо в браузере, без редактирования файлов.

## Стек

- **FastAPI** — Admin API для управления уровнями и вопросами
- **SQLAdmin** — удобная веб-админка поверх БД (таблицы, формы, поиск)
- **SQLAlchemy** — работа с базой данных
- **SQLite** — сама база (файл `english_bot.db`, создаётся автоматически)
- **pyTelegramBotAPI (telebot)** — сам телеграм-бот, режим polling

## Установка (Windows, PowerShell)

Открой папку проекта в PowerShell или в терминале VS Code и выполни по порядку:

```powershell
# 1. Создать виртуальное окружение
python -m venv .venv

# 2. Активировать его
.venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt
```

Если `python` не находится — установи Python 3.11+ с python.org и поставь
галочку "Add python.exe to PATH" при установке.

## Первый запуск: перенос старых вопросов в базу

В папке `txt/` лежат старые файлы с вопросами (`beginner.txt`,
`intermediate.txt` и т.д.) — они уже скопированы из старого проекта.
Чтобы один раз перенести их в базу данных:

```powershell
python scripts\seed_from_txt.py
```

Скрипт создаст файл `english_bot.db` и заполнит его уровнями и вопросами.
Повторный запуск скрипта ничего не сломает — уровни, которые уже есть в
базе, просто пропускаются.

## Запуск Admin API + веб-админки

```powershell
python run_api.py
```

Дальше доступны два интерфейса:

### 🖥️ Веб-админка (рекомендуется для повседневной работы)

**http://127.0.0.1:8000/admin**

Обычный удобный интерфейс с таблицами, как в привычных админках:

- слева в меню — разделы **Уровни** и **Вопросы**
- открой **Уровни → Create** — создать новый уровень (это и есть "новый
  файл" в терминах старого проекта): заполняешь `key` (техническое имя,
  латиницей, например `food`), `name` (то, что видит пользователь бота,
  например `🍎 Еда`), `description`
- открой **Вопросы → Create** — добавить один вопрос: выбираешь уровень
  из выпадающего списка, вписываешь `question` (слово на английском),
  `correct` (перевод, можно несколько вариантов через `/`), `hint`
  (подсказка)
- в списках можно искать, редактировать (иконка карандаша) и удалять
  (иконка корзины) любую запись
- если нужно добавить сразу много вопросов текстом (как раньше в
  блокноте) — для этого удобнее API-эндпоинт ниже, через админку такое
  массовое добавление придётся делать по одному вопросу

### 📋 API-документация (для массового добавления вопросов текстом)

**http://127.0.0.1:8000/docs**

Тут можно вставить сразу много вопросов одним куском текста
(`POST /levels/{level_id}/questions/bulk`), формат текста ровно такой
же, как раньше в блокноте:

```
break | ломать/сломать | to break the rules
speak | говорить | to speak English
```

Слева — слово (то, что бот покажет как вопрос), посередине — правильные
ответы через `/` (можно несколько вариантов), справа — подсказка.
Строки без двух `|` просто пропускаются, и API вернёт список того, что
не удалось разобрать.

Чтобы попробовать запрос — разверни его в `/docs`, нажми "Try it out",
впиши данные и "Execute".

## Запуск бота

В **отдельном** окне терминала (Admin API из предыдущего шага может
продолжать работать параллельно, либо можно его остановить — бот от него
не зависит):

```powershell
.venv\Scripts\activate
python run_bot.py
```

Бот подключится к Telegram и начнёт отвечать на сообщения. Останавливается
через Ctrl+C.

## Добавление нового уровня — пример

**Через админку** (`/admin`):

1. Запусти `python run_api.py`, открой `http://127.0.0.1:8000/admin`.
2. Раздел **Уровни → Create**: `key=food`, `name=🍎 Еда`,
   `description=Тема еда и напитки` → Save.
3. Раздел **Вопросы → Create**: выбери уровень `food` из списка, впиши
   `question=apple`, `correct=яблоко`, `hint=red or green fruit` → Save.
   Повтори для каждого вопроса.

**Через API** (быстрее для большого списка вопросов сразу):

1. Открой `http://127.0.0.1:8000/docs`.
2. `POST /levels`:
   ```json
   {"key": "food", "name": "🍎 Еда", "description": "Тема еда и напитки"}
   ```
   В ответе придёт `id` нового уровня, например `9`.
3. `POST /levels/9/questions/bulk`:
   ```json
   {
     "text": "apple | яблоко | red or green fruit\nbread | хлеб | you eat it every day"
   }
   ```

В обоих случаях новый уровень сразу появится у бота — перезапускать его не
обязательно (или просто открой `⚙️ Настройки → 🎯 Уровень сложности` в уже
запущенном боте), файл `english_bot.db` бот и API читают "вживую".

## О безопасности токена

Файл `key.py` с токеном бота добавлен в `.gitignore` — он не должен
попадать в git-репозиторий или куда-либо ещё, где его смогут увидеть
посторонние. Если токен всё же где-то засветился — можно бесплатно
перевыпустить его через [@BotFather](https://t.me/BotFather) командой
`/mybots` → выбрать бота → `API Token` → `Revoke current token`.
